# vivo主题增强 · 24.2.8.0-r1

适配原版 vivo主题 `24.2.8.0` 的独立 LSPosed 模块，从 [Modded-APKs](https://github.com/Escosis/Modded-APKs) 迁移。

## 使用方式（必看）

1. **只适配原版 vivo主题 `24.2.8.0`（`100024280`）**。请使用具备 Root 的 OriginOS 设备，以及支持 legacy Xposed 模块的 [LSPosed](https://github.com/LSPosed/LSPosed)。同版本号但 DEX 不同也不会启用；模块启动页可检查已安装宿主。
2. 在 LSPosed 中启用「vivo主题增强」，**只勾选 vivo主题**，不要同时启用其他同类模块。强制停止 vivo主题后，可点模块页的「打开 vivo主题」重新打开。
3. 在「本地与下载」点「本地导入」；预览已保存的资源时可选择「导出」。导入、导出未结束时，不要更新或停用模块。

## 主题解析说明（必看）

- **导入前检查 `.itz` 根目录。** 若 `theme.xml` 写有「该文件负责伪装成系统主题」，不要直接导入。确认它仅用于伪装后，先备份，再从副本中移除；否则资源可能被当作系统资源，无法从应用内正常删除。
- **只有图标的包请选择「图标」。** 如果根目录只有 `themeicon/`（内含 `icons.zip`）和 `description.xml`，不要作为「主题」导入。拆出的内包只有在本身具有完整主题结构和核心时，才可能改为 `.itz` 后按主题识别。
- 带 `style/` 的旧包、为替换式免 Root 导入制作的包，或面向其他 OriginOS 大版本的包可能不兼容。优先找适配当前系统的版本，修改前保留原包。
- 导入使用 vivo主题的原生解析和入库逻辑。主题需要有效的整主题核心；解析失败、文件冲突或入库失败不会被当成成功。

## Hook 效果

- 仅在匹配的宿主版本和 DEX 上启用功能。只处理本模块的导入、导出会话和文件选择结果，不接管其他页面的回调。
- 在线「本地与下载」每行最多四项，不横向翻页；在线、离线列表末尾均有「本地导入」。已保存资源的预览页增加「导出」。
- 调整本地会员、试用、购买和授权结果判断。**不增加服务端权益，不保证可下载付费资源，不生成有效授权密钥。**
- 跳过常规开屏广告和应用内升级检查，不覆盖所有推广入口、应用商店或系统更新。
- 对符合条件的本地 `.itz`，以及走原生旧下载流程、已经完整落盘的资源，兼容缺失授权材料或缓存零字节 key。仅在能核验原生摘要时继续原生解析，不替换下载、解析或数据库结果，不改非空 key 的处理，也不自动重试。
- 对已保存、确有整主题核心但缺少样式标记的部分主题补充分类，保留其他样式的原生判定。

## 支持格式

- **12 类 `.itz`**：主题、妙玩组件、动态壁纸、静态壁纸、行为壁纸、字体、图标、锁屏样式、控制中心、熄屏样式、视频铃声、输入法皮肤。
- **静态壁纸**：也可直接选择 `png`、`jpg`、`jpeg`、`webp`、`heic`、`heif`，以设备实际解码能力为准。
- **动态壁纸/字体**：额外支持 `mp4`/`ttf`。校验真实媒体内容，不只看扩展名；预览根据导入的视频画面或字体生成。

## 保存位置与反馈

- 设备一般使用 `/data/bbkcore/theme/` 下的私有目录，文件管理器需 Root 可读写，建议使用「导出」。目录对照见仓库 README。
- 旧试用资源无法使用时，先备份仍能导出的内容，不要批量删除。模块不会自动重新下载、重发授权或重跑导入。
- 注入、资源应用与 ROM 兼容性以设备实际表现为准。反馈问题请在 **LSPosed → 日志/模块日志** 搜索 `VivoTheme24`，并去除账号、授权材料及资源链接。
